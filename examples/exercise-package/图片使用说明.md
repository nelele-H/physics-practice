# 题目图片使用说明

需要图片时，在题包根目录创建 `assets` 文件夹，并把图片一起放入 ZIP：

```text
exercise-package.zip
├─ exercise.json
├─ questions.md
├─ answers.md
└─ assets/
   └─ question-04.jpg
```

在 `questions.md` 的对应题目中直接显示图片：

```markdown
![第 4 题配图](assets/question-04.jpg)
```

还可以在图片下增加一个查看原图的链接：

```markdown
[点击查看原图](assets/question-04.jpg)
```

学生端和教师批改端都会自动把大图缩放到页面宽度。点击题目图片或本地图片链接，会在当前页面打开大图；按 Esc、点击关闭按钮或点击黑色背景即可退出。

素材文件名请只使用英文字母、数字、点、横线、下划线和目录斜杠。支持 PNG、JPG、JPEG、GIF、WebP；素材总大小不超过 8 MB。建议把图片放入题包，不要依赖会失效或限制访问的外部图片网址。
