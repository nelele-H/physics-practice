# 小小物理站

轻量的物理专项练习、教师批改和成绩反馈网站。第一版使用静态页面、Node.js 接口和 SQLite，适合通过服务器 `IP:端口` 进行测试。

## 已实现

- 学生通过激活码自定义用户名和密码；
- 教师直接创建、改名、重置密码、停用、强制退出或永久删除学生账号；永久删除前自动备份，并级联清除该学生的作答和评分记录；
- Topic 1A、1B、1C 三套专项练习和 Topic 1 单元测试；
- 教师可上传标准 ZIP 练习包，自动检查题型、答案、总分、单位、小数位数和公式；
- 学生和教师都可以按练习编号、标题、副标题或 slug 搜索练习；练习列表每页显示 6 套；
- 新练习可先保存为草稿，再发布或下架；
- 支持带自动数据库备份和二次确认的永久删除，相关作答、评分和统计一并删除；
- 学生自主选题、保存、修改和删除答案；
- 教师开始批改前答案保持可编辑；
- 教师可锁定单个学生或批量锁定多个学生；
- 教师批改页会列出整套练习，未作答题也显示题目、参考答案和评分说明；
- 选择题和直接计算数值题自动判分，答案正确得满分、错误得 0 分；
- 数值题只填写数值，页面明确显示单位和保留的小数位数，支持 `1.1*10^2` 科学计数法；
- 问答、解释、实验评价等主观题由教师给分；
- 逐题评语和整套练习总体评语；
- 成绩发布后，只有未得满分题目显示正确答案；
- 每道题的作答人数、正确率和平均得分率；
- 后期计时考试所需的数据结构说明已经记录在网站方案中。

## 本地运行

需要 Node.js 20 或更高版本。

```text
pnpm install
node scripts/build-content.js
node server/app.js
```

默认地址：

```text
http://127.0.0.1:3000
```

允许其他设备访问时，服务默认监听 `0.0.0.0`。服务器防火墙需要开放相应端口。

## Ubuntu 24.04 部署

新服务器先按 [新服务器初始化_Ubuntu24.md](./新服务器初始化_Ubuntu24.md) 创建独立管理员账号并加固 SSH，再使用 [部署_Ubuntu24.md](./部署_Ubuntu24.md) 部署网站。项目已经附带 systemd、Nginx、SQLite 自动备份、首次安装、更新和发布包生成文件。

## 教师账号

当前数据库已经初始化了用户指定的教师账号。密码只以哈希形式保存在 SQLite 中，没有写入源码和说明文件。

如果需要在全新数据库中重新创建教师账号：

```text
设置 TEACHER_USERNAME 与 TEACHER_PASSWORD 环境变量
node scripts/seed-teacher.js
```

## 更新题目

题目来源位于相邻的 `AL_PH` 文件夹。修改练习或答案后运行：

```text
node scripts/build-content.js
node server/app.js
```

启动服务时会把新的题目文字、分值和答案同步到数据库。题目 ID 不变时，已有学生答案不会丢失。

教师新增练习无需修改服务器代码，可在“教师工作台 → 题库管理”上传 ZIP。完整格式见
[新增练习包格式.md](./新增练习包格式.md)，页面中也可以直接下载示例模板。

服务器管理员新增教师账号：

```bash
sudo bash /opt/physics-practice/deploy/create-teacher.sh
```

根据提示输入用户名和两次密码。密码不会显示，也不会写入命令历史；无需重启网站。

## 数据文件

```text
database/practice.db
database/exercise-content/
```

上传的原始练习包和图片保存在 `exercise-content` 中；正式服务器使用
`/var/lib/physics-practice/exercise-content`。

正式测试前建议复制一份空数据库备份。运行中数据库使用 WAL 模式，备份时优先停止服务后复制数据库文件。

## 测试阶段注意

使用普通 `http://IP:端口` 时，网络传输没有加密：

- 只使用专门的测试密码；
- 不得与邮箱、微信或其他系统密码相同；
- 尽可能限制访问来源；
- 正式长期使用前配置 HTTPS。

## 项目检查

```text
node scripts/check-project.js
```

该检查确认四套练习、静态页面和服务端文件完整，验证题型与数值题规则，并确认每个可评分小题都存在答案。
